## 我的方法论

**1. Motivation —— 动机**

- 为什么要做这件事？这件事有什么价值？
- 如果不做行不行？还有其他更值得去做的事吗？

**2. How —— 决定要做之后，怎么做**

- 别人有没有做过这件事？如果别人做过，我们的优势在哪？
- 如果别人没有做过，我们应该怎么做？

**3. Evaluation —— 做完之后怎么评估**

- 怎么评估当前工作？通过，还是重新迭代？
- 当前工作能否被沉淀复用？
